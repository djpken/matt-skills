# 其他

我常備但很少使用的工具，未在 plugin 中推廣。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：設定 Claude Code hooks，在執行前阻擋危險的 git 指令（push、reset --hard、clean 等）。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：將測試檔案從 `as` 型別斷言遷移至 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：建立包含章節、問題、解答與說明文字的練習目錄結構。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：設定包含 lint-staged、Prettier、型別檢查與測試的 Husky pre-commit hooks。
