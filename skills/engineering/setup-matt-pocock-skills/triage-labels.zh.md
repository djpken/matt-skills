# 分類標籤

這些 skill 使用五種標準分類角色來描述。此檔案將這些角色對應到此儲存庫 issue tracker 中實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 我們 tracker 中的標籤 | 意義 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage` | `needs-triage` | 維護者需要評估此 issue |
| `needs-info` | `needs-info` | 等待回報者提供更多資訊 |
| `ready-for-agent` | `ready-for-agent` | 已完整指定，可供 AFK agent 處理 |
| `ready-for-human` | `ready-for-human` | 需要人工實作 |
| `wontfix` | `wontfix` | 不會採取行動 |

當 skill 提到某個角色（例如「套用 AFK-ready 分類標籤」）時，請使用此表格中對應的標籤字串。

請編輯「我們 tracker 中的標籤」欄位，以符合您實際使用的詞彙。
