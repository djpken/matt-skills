description: 針對高信任度的主要來源調查一個問題，並將發現以 Markdown 檔案的形式記錄到 repo 中。用於：使用者想研究一個主題、蒐集文件或 API 事實，或想把讀資料的苦工交給背景 agent 時。
---

啟動一個**背景 agent** 來做研究，讓你可以邊等邊繼續工作。

它的任務：

1. 針對**主要來源**——官方文件、原始碼、規格、第一方 API——調查問題，而不是這些來源的二手整理。每個論述都要追溯回擁有它的來源。
2. 把發現寫進單一個 Markdown 檔案，並引用每個論述的來源。
3. 存放到 repo 已經在放這類筆記的地方；配合既有慣例，如果沒有，就放在合理的地方並說明放在哪裡。
